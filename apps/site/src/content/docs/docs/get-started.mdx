---
title: Get started locally
description: Run Artifact Server on a laptop and publish a first immutable artifact version.
---

The local target runs directly on the host with SQLite, local blob storage, loopback-only content origins, and frictionless local-owner browser access. It requires Node.js 24.12 or newer.

## Install the release

<Steps>
  <Step title="Download and verify Artifact Server 0.1.0">
    ```sh
    curl -LO https://github.com/plannotator/artifact-server/releases/download/v0.1.0/artifact-server-0.1.0-node.tar.gz
    curl -LO https://github.com/plannotator/artifact-server/releases/download/v0.1.0/SHA256SUMS
    grep ' artifact-server-0.1.0-node.tar.gz$' SHA256SUMS | shasum -a 256 --check
    tar -xzf artifact-server-0.1.0-node.tar.gz
    ```

    The checksum command must report `OK`. You can also [verify the GitHub attestation](/docs/security/) before extracting the archive.
  </Step>
  <Step title="Open Artifact Server">
    ```sh
    ./artifactserver/bin/artifactserver open
    ```

    Open the printed URL. To use `artifactserver` from any directory, keep the extracted directory in a stable location and add its `bin` directory to your `PATH`. The [CLI guide](https://github.com/plannotator/artifact-server/blob/v0.1.0/docs/cli.md) shows the exact setup.
  </Step>
  <Step title="Publish from an agent">
    Connect the agent to the running installation:

    ```sh
    ./artifactserver/bin/artifactserver connect
    ```

    Then install the Artifact Server skill:

    ```sh
    npx skills add plannotator/artifact-server
    ```

    Then ask the agent to upload the finished file. In clients that expose skills as slash commands:

    ```text
    /artifact-server upload that HTML design doc
    ```

    The agent returns the full-screen review link first.
  </Step>
</Steps>

## Run from source

Use this path when contributing to Artifact Server. It also requires pnpm 10.34.3.

```sh
git clone https://github.com/plannotator/artifact-server.git
cd artifact-server
pnpm install
pnpm dev
```

Open the printed URL. `pnpm dev` starts both the web application and API. Do not run `artifactserver open` as a second setup step. Run CLI commands from the checkout with `pnpm artifactserver <command>`.

## Local access behavior

Requests from the loopback application origin can obtain the local-owner session without a sign-in form. This behavior does not disable authentication for remote access: hosted and private-team deployments still use their configured identity provider.

<Aside type="caution" title="Loopback is the boundary">
Do not expose the local-owner development target directly to another device or a public network. Use a private-team deployment when Artifact Server must be reachable remotely.
</Aside>
